Tools

两个工具：一个算评测，一个在装插件前先踩刹车。都在本地跑，不上传数据。

  • 01 RAG 检索评测

    JSONL / JSON 数组 / 单个对象都能进；算 Recall@k、MRR、Hit@1、延迟、成本；对比上次、只看未命中、导出 Markdown / CSV。

  • 02 DSH 插件安全审计

    装插件前查身份、安装脚本、数据外发、凭据、混淆、自启动；网页生成命令和人工复核清单，不执行目标代码。

    Checklist No execution CLI
    Live

为什么做

Notes
01 / 口径

评测和审计都需要固定口径；没有口径的数字和“看起来安全”都没法复现。

02 / 本地

评测在浏览器算；审计命令在你终端跑。工具本身不碰你的仓库和密钥。

03 / 能复用

评测结果能贴进文章，审计清单能贴进 PR 或 Issue；不是一次性截图。
