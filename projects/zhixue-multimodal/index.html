智学多模态

课堂多模态 Agent：WhisperX 转写 + OCR + 页级对齐 + 课程内 RAG；短片段 ECR 0.333→0.833，长课暴露边界。

FastAPIWhisperXRapidOCRRAGPython

Metrics

  • 短片段 ECR 0.333 → 0.833
  • 全量 157 题 ECR 0.416 → 0.824
  • 长课命中 25.5%（全上下文 41.8%）
  • 长课成本 约 1/25

数据口径：项目仓库 docs/ceqa/PILOT_REPORT.md 与 docs/CHANGELOG.md；CEQA 为 draft 版本。

它是什么

把一节课的录像变成可检索的时间轴：ASR 转写、PPT/板书 OCR、页级对齐，再用课程内 RAG 回答并给出来源。

目标很具体：复习时能跳回“第 12:30，第 8 页”。

界面

我做了什么

  • 负责 API 与 Agent/RAG 段：FastAPI 接口、课程内检索、回答带来源。
  • 把字幕、页面、时间轴对齐成可回链的证据；回答可以回到具体页。
  • 建 CEQA 评测集（240 题，draft），用 ECR / AnsAcc 而不是“看起来不错”评估。

结果

测试集指标混合检索全上下文
短片段（7 段 / 27.6 分钟）ECR / 命中率0.833 / 48.5%—
全量 157 题ECR / 命中率0.824 / 58.0%61.8%
长课 64.95 分钟命中率25.5%41.8%

短片段上 RAG 赢得干净；长课上输给全上下文。长课成本约为它的 1/25，短片段/全量约 1/3。详细复盘写在博客里。

边界

  • 只评测检索层，不评估生成质量。
  • CEQA 是 draft，数字会随标注修订。
  • 长课需要“分块摘要 + 全局问题”的另一套方案，不是同一套 RAG 打所有场景。
